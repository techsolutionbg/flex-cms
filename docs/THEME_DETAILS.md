# Детайли за тема

Административната страница `/themes/{id}` (или `/admin/themes/{id}` в production)
използва `GET /api/admin/themes/{id}`. Достъпът е само за супер администратор.
Темата може да е локална, да присъства само в каталога или да е активна.

Локалният `theme.json` има предимство пред метаданните в `themes/index.json`.
Публичният API отговор не включва локални файлови пътища. Пакетът не се сваля
за разглеждане на подробности. При недостъпен каталог локалните данни остават
достъпни, а потребителят вижда предупреждение.

За пълни подробности преди инсталиране публикувайте следните незадължителни
полета в записа на темата в `themes/index.json`:

```json
{
  "id": "flex-starter",
  "name": "Flex Starter",
  "description": "Минимална PHP тема за Flex CMS.",
  "author": "Flex CMS",
  "license": "GPL-2.0-or-later",
  "tags": ["PHP", "Персонализируема"],
  "supports": {"menus": true, "navigation": true},
  "menu_locations": {"primary": "Основно меню"},
  "minimum_platform_version": "0.1.47",
  "homepage": "https://example.com",
  "documentation": "https://example.com/docs",
  "manifest_url": "https://updates-flex-cms.kriskata.com/themes/manifests/flex-starter.json",
  "screenshot_url": "https://updates-flex-cms.kriskata.com/themes/previews/flex-starter.png"
}
```

Липсващите полета се обозначават, без да се измислят стойности.
Съвместимостта и наличните действия използват същия избор на релийз като
инсталатора: версия на платформата, PHP и конфигуриран канал. Историята показва
и несъвместимите релийзи с причината за несъвместимостта. Наличието на подпис
е обозначено като метаданни; криптографската проверка се изпълнява преди
инсталиране от съществуващия downloader.

Страницата се отваря в запазван административен таб, използва универсалните
collapsible секции и бутони и поддържа стандартното презареждане на таба.
